# Исключения из проверки иероглифов (CJK) для tools/l10n/check_locale.py.
#
# Формат строки:  <file>:<name>  # причина
#   <file> — имя файла ресурсов, как он передан в --files (например strings.xml);
#   <name> — имя ресурса из атрибута name;
#   после `#` — причина для человека (не разбирается, может отсутствовать).
#
# Исключение снимает ТОЛЬКО проверку иероглифов. Плейсхолдеры, теги,
# escape-последовательности и наличие ключа проверяются как обычно: строка
# ниже не разрешает сломать форматирование.
#
# Сюда попадают только функциональные иероглифы — значения, которые нельзя
# перевести, не сломав функциональность. Непереведённый текст в исключения
# не вносится, его надо переводить.
#
# Файл читается автоматически при запуске проверки; --allowlist PATH указывает
# другой файл (несуществующий явный путь — ошибка).

strings.xml:speech_services_mimo_voice_id_placeholder   # примеры значений параметра API: имя голоса MiMo (冰糖) рядом с mimo_default
strings.xml:speech_services_mimo_voice_id_hint          # реальные значения параметра API: список голосов MiMo (冰糖, 茉莉, 苏打, 白桦)
strings.xml:graph_char_for_measurement                  # образец иероглифа 中 для измерения метрик шрифта
strings.xml:agreement_serious_content                   # официальное название НПА КНР 《人工智能拟人化互动服务管理暂行办法》 внутри англ. юридического текста
